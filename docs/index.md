# Darkaspersky

> A compounding knowledge base of Elden Ring lore, built on the [Karpathy LLM Wiki](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f) framework.

Elden Ring's story is told through fragments — scattered across item descriptions, NPC dialogue, environmental details, and loading screens. No single source tells the whole story. This wiki exists to **surface the connections between those fragments**, cross-referencing every known lore source to reveal hidden relationships, character motivations, and the true shape of the narrative.

## About This Project

This wiki is built on the [Karpathy LLM Wiki](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f) framework — a pattern where an LLM acts as a "compiler" that reads raw source materials and produces a structured, cross-referenced knowledge base that compounds over time.

The raw source material lives in `raw/` and includes verbatim item descriptions, NPC dialogue transcripts, environmental observations, cinematic narration, and community analysis. The wiki pages in `docs/` are compiled from these sources, with every claim traceable back to specific source files.

See the [Compilation Log](log.md) for the history of changes.
