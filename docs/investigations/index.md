# Investigations

> Deep dives into the biggest unsolved questions in Elden Ring's lore, using cross-referencing analysis to propose answers.

Unlike the wiki pages (which catalog what is known), investigations take positions. They weigh contradictory evidence, build timelines, and propose verdicts. They are the Karpathy LLM Wiki framework's most powerful feature — synthesizing connections across hundreds of raw sources that no single playthrough could reveal.

## How Investigations Work

Each investigation follows the same structure:

1. **The Question** — what we're trying to answer
2. **Evidence gathering** — all relevant item descriptions, dialogue, environmental details, and cut content
3. **Cross-reference analysis** — the key section, where connections between sources are mapped
4. **Proposed timeline** — reconstructing the sequence of events
5. **Verdict** — a definitive position, defended with evidence
6. **Remaining gaps** — what we still can't explain

Investigations are designed to be challenged. If new evidence emerges (new raw sources, DLC content, community discoveries), the verdict should be revisited.
